# رفيق الكلية

تطبيق Flutter تجريبي يجمع محتوى المواد من مجموعات الدراسة في مكان واحد، ويعرض ملخصات المحاضرات والملفات والمهام ومؤشرًا لتقدم المنهج. الواجهة عربية باتجاه RTL.

## فتح التطبيق

ثبّت Flutter، ثم من مجلد المشروع شغّل:

```bash
flutter pub get
flutter run
```

يعمل التطبيق افتراضيًا في **وضع المعاينة** ببيانات توضيحية محلية، حتى يمكن استكشاف الشاشات دون خادم. تظهر عبارة «معاينة تفاعلية · بيانات توضيحية» في الشاشة الرئيسية. يمكن تجربة تصنيف التحديثات، المقررات، المهام، ومحادثة المساعد. ردود المساعد ومحتوى المجموعة في هذا الوضع أمثلة تجريبية وليست بيانات حقيقية.

## توصيل Backend

لتعطيل وضع المعاينة وتوصيل خادم:

```bash
flutter run --dart-define=DEMO_MODE=false --dart-define=API_BASE_URL=https://your-api.example.com
```

المسارات المتوقعة: `GET /api/schedule`, `/api/assignments`, `/api/courses`, `/api/alerts`، و`POST /api/study-buddy/chat`. يوفر الخادم أيضًا مسارات حالة واتساب وإرسال الرسائل.

التطبيق الحالي لا يتصل بواتساب مباشرة ولا يقرأ المجموعات أو ملفاتها تلقائيًا. هذه الإمكانية تحتاج Backend وتكاملًا رسميًا مناسبًا؛ يجب أن يوفّر الخادم الرسائل والوسائط المصرح بها للتطبيق. لا تضع مفاتيح WhatsApp أو أسرار الخادم داخل تطبيق Flutter.

## المجلدات

- `lib/screens`: الشاشات والتنقل.
- `lib/services`: الاتصال بالخادم وبيانات المعاينة وتصدير المحادثة.
- `lib/models`: نماذج البيانات.
- `lib/theme`: ألوان وخطوط الواجهة.
- `test`: اختبارات تحويل بيانات API.
